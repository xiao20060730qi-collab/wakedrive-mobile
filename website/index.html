CAPABILITIES

不只看眼睛，
而是理解整个驾驶状态。

从眼部、嘴部到头姿与手部动作，多个维度共同构成一次判断。每一个告警，都有可回溯的依据。

01

眼部状态

闭眼时长、闭眼占比与眨眼频率联合判断，针对眼镜反光与遮挡做归一化处理。

02

哈欠识别

嘴部开合与持续时间双阈值判断，三分钟内两次以上哈欠自动升级提醒等级。

03

头部姿态

6D 姿态估计识别低头与视线偏离，低头导致的人脸丢失同样触发对应语音与报警。

04

分心行为

接打电话、抽烟、喝水抬手分别识别，触发不同强度与文案的即时提醒。

05

人脸丢失

连续两帧确认恢复，杜绝单帧误检。8 秒横幅、12 秒语音、15 秒刺耳报警与弹窗逐级升级。

06

车速联动

高德定位持续测速，车辆启动自动进入监测且不可强制关闭；停车三分钟确认休息后结束。疲劳升级时自动推荐就近服务区并支持一键导航。

07

连续疲劳指数

多指标归一化后逐帧平滑，20 / 45 / 70 三档下限约束等级，不再出现固定分数跳变。

08

事件存证

告警时间轴、抓拍快照、监测报告与统计分布，按账号隔离保存，随时复核。

09

AI 解析与权限

AI 分析窗口解读本次监测，管理员拥有独立的账号、密码与删除管理权限。

PIPELINE

从一帧画面，
到一次及时的提醒。

整条链路在设备端完成视觉推理，只有必要的事件快照按账号保存。快，但不把画面交给远方。

  1. 01 / 采集与预处理

    OpenCV 画质归一化

    电脑端用 OpenCV.js 完成 ROI 裁剪、灰度化、亮度和清晰度检测与 CLAHE 增强，手机端使用原生图像管线。

    OpenCV.js · Canvas · CameraX
  2. 02 / 推理

    六模型并行

    人脸关键点、目标检测、人体姿态、头部姿态、MobileNetV3 眼状态与因果 TCN 时序模型同时运行，输出多维指标。

    MediaPipe · ONNX Runtime Web
  3. 03 / 评分

    连续疲劳指数

    指标归一化取最大值，叠加等级下限与平滑，逐帧输出 0–100 的风险分数。

    四等级 · 连续更新
  4. 04 / 响应

    分级提醒与存证

    语音、刺耳警报、弹窗与事件快照按等级升级，恢复后自动停止。

    Alarm · Snapshot · Report

TRUST & PRIVACY

提醒可以很响亮，
数据必须很克制。

视觉推理优先留在设备端，事件存证按账号隔离。安全提醒之外，不做多余的事。
