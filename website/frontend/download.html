INSTALL GUIDE

三步装好，马上开始。

01 Android

  1. 向管理员获取适配机型的安装包，或使用上方配置好的直链下载。
  2. 在系统提示中允许浏览器“安装未知应用”，完成 APK 安装。
  3. 打开应用，授予相机与定位权限，登录驾驶账号后开始监测。

建议将应用固定到桌面，并在监测时连接电源。

02 iPhone

  1. 联系管理员获取已签名的安装包或 TestFlight 邀请链接。
  2. 使用 Safari 打开安装链接，按提示完成安装。
  3. 如为企业签名，请在“设置 → 通用 → VPN 与设备管理”中信任证书后再打开。

iOS 端需要保持屏幕常亮，并在监测时允许麦克风与相机权限。

03 Web / PWA

  1. 使用手机浏览器打开驾驶工作台并登录。
  2. 在浏览器菜单中选择“添加到主屏幕”，即可像 App 一样启动。
  3. 监测时保持页面在前台，并允许声音播放。

电脑端建议使用 Chrome / Edge 最新版本，并允许摄像头权限。
