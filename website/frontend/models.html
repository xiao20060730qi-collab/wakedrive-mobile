02 / IMAGE CLASSIFICATION
新增已接入

MobileNetV3-Small

轻量图像分类 · 眼状态判定

已接入浏览器本地推理：MediaPipe 定位左右眼区域，OpenCV 完成裁剪、灰度化与 CLAHE 增强，MobileNetV3-Small 输出睁眼/闭眼概率，与 EAR 特征交叉验证。权重基于公开 MRL 眼部数据集训练，用于补充局部图像证据。

输出
睁眼 / 闭眼概率；闭眼概率与 EAR、时序模型融合

04 / TEMPORAL MODELING
新增已接入

因果 TCN

Temporal Convolutional Network · 时序建模

已接入浏览器本地推理：以 5Hz 采样 EAR、MAR、PERCLOS、头姿与闭眼时长，32 帧因果窗口输出时序疲劳概率，与规则判断交叉验证。权重由站内时序规则蒸馏训练，用于学习式融合与平滑，不代表道路或临床诊断。

输入
32×6 特征序列（EAR、MAR、PERCLOS、横向/俯仰头姿、闭眼时长）
输出
alert / fatigued 概率；与眼状态分类和规则结果融合
接入状态
已连接实时监测；ONNX Runtime Web 本地推理，需完成 6.4 秒有效采样
TCN 原始论文 ↗查看实时监测 →

07 / IMAGE PROCESSING
新增已接入

OpenCV

OpenCV.js 4.3 · 图像处理库

OpenCV.js 在浏览器内完成眼部 ROI 裁剪、灰度化、亮度/对比度/Laplacian 清晰度评估与 CLAHE 增强，为 MobileNetV3 提供稳定输入，并在监测页实时显示画面质量。OpenCV 是视觉处理库，不是新增训练模型。

输入
摄像头视频帧与 MediaPipe 眼部区域
输出
亮度、对比度、清晰度、画质等级与增强后的眼部图像
接入状态
已连接实时监测；OpenCV.js WASM 在浏览器本地运行
